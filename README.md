# Landing Page — Pousada

Landing page para uma pousada, desenvolvida com foco em apresentar a hospedagem, destacar seus diferenciais e proporcionar uma experiência de navegação agradável, intuitiva e responsiva aos visitantes.

O projeto tem como objetivo criar uma presença digital para a pousada, facilitando o acesso às informações e o contato direto de potenciais hóspedes por meio do WhatsApp.

## Objetivo

Desenvolver uma página institucional moderna, visualmente atrativa e responsiva, apresentando informações relevantes sobre a pousada e incentivando os visitantes a entrarem em contato para consultar disponibilidade e realizar reservas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades previstas

- Apresentação da pousada
- Seção de acomodações
- Galeria de imagens
- Apresentação dos diferenciais
- Informações sobre localização
- Integração direta com o WhatsApp
- Layout responsivo para dispositivos móveis, tablets e desktops
